Two products, one principle

Nothing important moves without being seen, approved and checked.

Software now acts for us: moving our plans between apps, and writing code alongside us. Both are fast, and both quietly get things wrong. Recast and Relay put a person in the loop at the moment that matters, and then check the result against reality.

For everyone

Recast

The context layer between your apps. Select what matters on any page: a person, a time, a place, a message. Press the pieces together into one object, see exactly what will happen, place it in Google Calendar, Gmail, Tasks, Docs, GitHub or Linear, and Recast reads it back to prove it landed.

  • Conflicting information shows where each value came from
  • Nothing is written until you approve; everything can be undone
  • Save what you did as a personal workflow and run it again
Try the demoHow Recast works
For software teams

Relay

The integration trust layer for people and coding agents. Two changes can each pass their own tests and still break the project together. Relay rehearses them together before anything is applied, blocks the break, and explains the cause.

  • Works with real agents (Claude Code) and any editor
  • Only evidence Relay gathered itself counts; agents cannot approve
  • Live shared editing, presence and line history in a browser IDE and VS Code
