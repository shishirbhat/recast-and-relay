Relay walkthrough

Green, green, broken.

Two coding agents each finish a task, and each passes its own tests. Step through what happens next, first without Relay and then with it. This replays Relay's recorded experiment, shortened: the project, the checks, the results and Relay's explanation are taken from it. The last step shows how it ends once the owners fix it.

Use the arrow keys to step through. Switch workflows at any time.

The recorded results

The same scenario with real agents (Claude Code, headless): two rounds of three trials, each trial run in both workflows from the same starting project.

Limits. The tasks were designed to set up this conflict, in a five-file project, with one agent product. In one round, an agent noticed the problem and mentioned it in chat; that warning gated nothing.
